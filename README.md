# Health App MVP

A full-stack health monitoring and care management platform designed to bridge patients and doctors seamlessly, built during a high-intensity hackathon sprint.

## 🔗 Live Demo
* **Live Application:** [Insert your Vercel URL here]

## 🚀 Tech Stack
* **Framework:** Next.js (React, TypeScript, Tailwind CSS)
* **Database & Auth:** Supabase (PostgreSQL)
* **Deployment:** Vercel

## ✨ Core Features
* **Patient Portal:** Track daily wellness metrics (sleep, mood, activity), log medication adherence, submit symptom or side-effect reports, and send clinical questions.
* **Doctor Portal:** Instantly view patient summaries, review adherence percentages, analyze side-effect logs, and update active care plans or medications in real-time.
